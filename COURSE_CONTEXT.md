# Course & Portfolio Context

## Purpose

This repository is a structured SQL learning lab built from practical exercises completed while studying advanced SQL concepts in MySQL.

The original study package contains:

- exercise files by section;
- instructor/reference solution files;
- a final project;
- a final project with hints;
- a final project solution file.

## Public portfolio policy

The repository does **not** republish instructor answer-key files verbatim as if they were original personal or production work.

Instead, the public portfolio contains:

- the SQL concepts practiced;
- the analytical problems explored;
- curated and reviewed practice implementations based on the exercise/reference material;
- simplified and documented queries;
- corrections or stronger alternatives explicitly identified by the reference notes;
- clearly commented small refinements where a query was aligned more closely with the wording of the analytical question;
- a final case study combining multiple SQL concepts.

## Study progression

The original exercise material is organized into five technical sections plus a final project:

1. Joins
2. Subqueries and CTEs
3. Window functions
4. SQL functions
5. Analytical / data-quality techniques
6. Final analytical case study

The repository mirrors this learning progression while keeping the public content concise and portfolio-oriented.

## Current status

Reviewed SQL practice files are now available for all five technical sections and the final baseball case study.

Future improvements can include query-result evidence and independently designed SQL business cases that go beyond the original course exercise set.
