# 04 — SQL Functions

## Scope

This section focuses on transforming, standardizing, and interpreting values directly in SQL.

## Concepts practiced

- Numeric functions
- Datetime functions
- String functions
- Pattern matching
- NULL-handling functions

## Analytical skills

The exercises reinforce how SQL functions can be used to:

- Derive metrics from numeric values
- Extract and compare date components
- Calculate time intervals
- Standardize and combine text fields
- Search text patterns
- Replace, detect, and reason about missing values
