# Final Case Study — Baseball Data Analysis

## Overview

The final SQL project brings together the techniques practiced throughout the lab in a broader analytical case based on baseball data.

The objective is to answer multi-step analytical questions across schools, team salaries, player careers, and player characteristics.

## Part I — School Analysis

Focus areas:

- Number of player-producing schools by decade
- Schools that produced the highest number of players
- Top schools within each decade

Main SQL techniques:

- Numeric functions
- Joins
- Aggregation
- CTEs
- Window functions and ranking

## Part II — Salary Analysis

Focus areas:

- Team spending over time
- Identifying the highest-spending group of teams
- Cumulative spending by team
- Identifying when spending crosses a defined threshold

Main SQL techniques:

- Aggregation
- `NTILE()`
- Window functions
- Rolling / cumulative calculations
- Min / max style filtering
- CTEs

## Part III — Player Career Analysis

Focus areas:

- Player age at debut and final game
- Career length
- Starting and ending teams
- Long-career players who began and ended with the same team

Main SQL techniques:

- Datetime functions
- Joins
- Conditional filtering
- Derived metrics

## Part IV — Player Comparison Analysis

Focus areas:

- Players sharing the same birth date
- Batting-side distribution by team
- Changes in average player height and weight across decades

Main SQL techniques:

- String aggregation
- Conditional aggregation / pivot-style summaries
- CTEs
- `LAG()` and window functions
